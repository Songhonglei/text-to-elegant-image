How it works

Quick start

Running in under a minute

Node.js ≥ 18 and any recent Chrome / Chromium is all you need.

# Clone and install the single dependency (puppeteer-core)
git clone https://github.com/Songhonglei/text-to-elegant-image.git
cd text-to-elegant-image
bash scripts/setup.sh

# Render an HTML file to a high-DPI PNG (long image, width 600)
node scripts/export_image.js page.html ./output/card.png 600

# Fixed 3:4 poster / cover card (600 x 800)
node scripts/export_image.js page.html ./output/poster.png 600 --fixed-height 800

# Optional: set a default output directory
export T2EI_OUTPUT_DIR="$HOME/my-images"
FlagWhat it does
--fixed-height <px>Skip auto-height and render a fixed canvas — used for 3:4 posters and cover cards.
--frame <px>Canvas frame padding on all four edges. Defaults to 32px; --frame 0 disables it.
--flatTurn off the card-style background and let content sit flat on the canvas.
--author "…"Replace the footer line with your own attribution.
--no-footerRemove the footer entirely.

FAQ

Common questions

QWhat goes in, and what comes out?

Markdown or plain text goes in; a high-resolution PNG comes out — by default a vertical long image, optionally a 3:4 quote poster or cover card. The renderer writes the file to your output directory and returns the path.

QDoes it call any paid image-generation API?

No. Rendering is entirely local: the content is laid out as HTML/CSS and screenshotted by headless Chrome. There is no diffusion model and no external image API, so your content never leaves your machine.

QWhy is emoji banned in generated HTML?

Headless Chrome ships without colour-emoji fonts, so emoji render as tofu boxes. Use CSS shapes or inline SVG instead — scripts/check_emoji.py fails the build before screenshotting if any slip through.

QCan I add my own style?

Yes. Copy any file in resources/styles/ as a starting point — each one is self-contained, holding its CSS, HTML skeleton, --t2e-* component colour mapping, font injection and decorations. Drop in a new numbered file and it becomes selectable.

QDoes it push images to Slack / Telegram / WeChat?

Not built in. This edition focuses on generation and hands you a local PNG path; wire up your platform's bot or API downstream. Optional adapters may land in a future version.
